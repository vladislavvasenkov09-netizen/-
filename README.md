# ЧЕ ЭТО ЗА ХУЙНЯ???
Блять, я хуй его знает для кого я это пишу, но что бы джуном стать, надо свой гитхаб вести, редми писать и тд, так что просто для справочки попрактиковаться.

Ну короче, Quiz-Game это такая игра-викторина на 3 разные категории по 10 вопросов на каждую. По главному меню уже можно понять что это просто хуйня побаловаться на 5-10 минут. Но для меня это ебанутое открытие, потому что я, который всего около 3-4 месяцев изучения питона, написал достаточно большой скрипт, это как я считаю ахуено.
Ну короче, тут можно отвечать на вопросы, посмотреть категории вопросов, сохранить их в отдельном файле (это предусмотрено скриптом, самому файл не надо создавать и тд). Ну и добавлять свои вопросы к определенной категории, что бы было интересней, я хз.

# КАК ЭТУ ХУИТЕНЬ ЗАПУСТИТЬ??? 
Все ебануто легко, просто нужно скачать этот архив и распаковать его в новой папке ваще похуй где, хоть на рабочем столе, хоть прям на диске, разницы  нет. После этого спокойно из одной папки запускайте main.py
Имейте ввиду, что если исполняемый файл main.py будет запущен не из одной папки с файлами формата json то скрипт упадет с ошибкой и все нахуй сломается.
